# 08 工程命令与检查清单

## 1. 执行位置与包管理器

所有命令必须在 `${PROJECT_NAME}-ui/cloud/client` 工程目录中执行，不要在仓库根目录或管理后台工程中执行。

本工程使用 **yarn**（仓库内为 `yarn.lock`）；管理后台工程使用 npm，两者不要混用。

## 2. 常用命令

| 命令 | 作用 |
| --- | --- |
| `yarn dev` | 启动 H5 开发环境 |
| `yarn dev:weapp` | 启动微信小程序开发环境 |
| `yarn openapi` | 生成消费端 API SDK（`node scripts/generate-api.js`） |
| `yarn build` | 构建消费端工程，仅在任务需要构建验证时执行 |

新增、删除、启用、禁用页面或模板后如开发者工具不生效，重跑 `yarn dev` 或 `yarn dev:weapp`。

## 3. API 生成与目录边界

- 消费端 API 非特殊情况**不得手写**：后端提供 Swagger/OpenAPI 后，在本工程执行 `yarn openapi` 生成 `src/api/sdk.gen.js`。
- `src/api/sdk.gen.js` 为生成文件，**不得手动修改**。
- 如确有无法通过 OpenAPI 生成的特殊 API，必须先说明原因并确认方案，再修改 `src/api/index.js` 等手动接口文件，不得私自固化未经确认的接口契约。
- 请求实例与拦截逻辑在 `src/api/request.js`，由 `src/app.js` 注册进 `extendApp`，页面通过 `this.yz.app.getApi()` 调用。

## 4. 多端适配边界

消费端**不做多媒体适配**（屏幕 / 分辨率响应式适配）：

- 只按设计稿的目标屏幕尺寸实现。
- 不写媒体查询，不使用响应式断点。
- 不为其他分辨率或设备尺寸单独适配。

H5 与微信小程序的行为差异通过 Tee 多端框架与开放能力处理，**不通过响应式布局处理**。

## 5. 评审清单

评审消费端代码时优先检查：

- [ ] 是否先读了 `docs/client/` 各分册并按要求通过 <https://doc.youzanyun.com/llms.txt> 查询对应文档。
- [ ] 是否违反 Vue 2 Options API、多端模板、开放组件、`app.json`、生命周期、平台版本等约束。
- [ ] 是否误把独立 `.js` 文件的可选链限制扩大到 `.vue` 文件。
- [ ] 是否按目标项目的 `styles/global.scss` 能力选择样式单位：有内置 `rpx` 动态单位计算函数时优先 `rpx`，否则使用 `px`。
- [ ] 是否混淆全局 `yz.*` API 与页面实例 `this.yz.*` 能力（如 `yz.navigateTo` 不能写成 `this.yz.navigateTo`）。
- [ ] 页面初始化请求是否都在 `dataReady` 中发起，`created` 是否只做事件注册，`mounted` 是否只做 DOM / 实例操作。
- [ ] 页面 / 插槽 / API / 数据是否和文档标识、字段、调用时机一致。
- [ ] 服务端 API 名称、版本、能力包、token 获取方式、消息 topic、扩展点契约是否和文档一致。
- [ ] 是否遗漏 H5 / 小程序差异、错误处理、loading、空态、重复请求、销毁清理。
- [ ] 是否手改生成文件或引入未确认兼容的新依赖。

## 6. 自检命令

```shell
cd ${PROJECT_NAME}-ui/cloud/client

# 独立 .js 文件中的可选链（应无输出）
grep -rn "?\." src --include="*.js"

# 媒体查询（应无输出）
grep -rn "@media" src --include="*.vue" --include="*.scss" --include="*.js"

# 非多端 API（应逐条确认是否误用）
grep -rnE "\b(window|localStorage|sessionStorage|getApp|getCurrentPages)\b" src --include="*.js" --include="*.vue"
```
