# 07 代码最佳实践

一些通用的功能实现逻辑，可以直接复制后少量修改快速完成功能。

## 1. 接口 loading 及提示

模板：

```html
<template>
  <view>
    <t-toast ref="t-toast" />
    <t-dialog ref="t-dialog" />
  </view>
</template>
```

逻辑：

```javascript
import { Toast as VanToast, Dialog as VanDialog } from "@youzan-cloud/tee-ui";
import Toast from "@youzan-cloud/tee-ui/dist/toast/toast";
import Dialog from "@youzan-cloud/tee-ui/dist/dialog/dialog";

export default {
  components: {
    "t-toast": VanToast,
    "t-dialog": VanDialog,
  },
  methods: {
    async initLoad() {
      try {
        Toast.loading({
          message: "加载中...",
          forbidClick: true,
          duration: 0,
          context: this,
        });
        const params = {};
        const res = await this.yz.app.getApi().customRequest(params);
        console.log("res", res);
      } catch (error) {
        console.log("error", error);

        Dialog.alert({
          title: "错误提示",
          message: (error.data || {}).message || error.message || error.errMsg || "请求失败",
          context: this,
          confirmButtonColor: "#ee0a24",
        });
      } finally {
        Toast.clear();
      }
    },
  },
};
```

要点：

- `Toast.loading` 必须配 `duration: 0` 与 `context: this`，并在 `finally` 中 `Toast.clear()`。
- 错误信息按 `error.data.message` → `error.message` → `error.errMsg` → 兜底文案的顺序取值。

## 2. 列表查询（分页）

模板：

```html
<template>
  <view>
    <t-list
      :loading="loading"
      :finished="isLast"
      finished-text="没有更多了"
      @load="onLoad"
      v-if="list.length"
    >
      <view
        class="custom-item"
        v-for="(item, index) in list"
        :key="index"
      >
      <!-- custom content -->
      </view>
    </t-list>
    <t-empty v-else-if="inited && !list.length" text="暂无数据" />
    <t-toast ref="t-toast" />
    <t-dialog ref="t-dialog" />
  </view>
</template>
```

逻辑：

```javascript
import { Toast as VanToast, Dialog as VanDialog, Empty } from "@youzan-cloud/tee-ui";
import Toast from "@youzan-cloud/tee-ui/dist/toast/toast";
import Dialog from "@youzan-cloud/tee-ui/dist/dialog/dialog";

export default {
  components: {
    "t-empty": Empty,
    "t-toast": VanToast,
    "t-dialog": VanDialog,
  },
  data() {
    return {
      isLast: false,
      loading: false,
      pageNum: 1,
      total: 0,
      list: [],
      inited: false,
    };
  },
  dataReady() {
    this.search(true);
  },
  methods: {
    onLoad() {
      if (!this.inited) return;
      this.search();
    },
    async search(init) {
      try {
        if (init) {
          this.pageNum = 1;
          this.isLast = false;
          this.list = [];
          this.total = 0;
        }
        this.loading = true;
        Toast.loading({
          message: "加载中...",
          forbidClick: true,
          duration: 0,
          context: this,
        });

        const params = {
          pageNum: this.pageNum,
          pageSize: 10,
        };

        const res = await this.yz.app.getApi().requestList(params);

        this.total = res.data.total;
        this.list = [...this.list, ...(res.data.list || [])];
        this.isLast = this.list.length >= this.total;
        this.pageNum++;
      } catch (error) {
        console.log("error", error);

        Dialog.alert({
          title: "错误提示",
          message: (error.data || {}).message || error.message || error.errMsg || "请求失败",
          context: this,
          confirmButtonColor: "#ee0a24",
        });
      } finally {
        Toast.clear();
        this.loading = false;
        this.inited = true;
      }
    },
  },
};
```

要点：

- 首屏（以及所有页面初始化请求）一律在 `dataReady` 中触发，不要放在 `created` / `mounted`，否则 `this.yz` 可能尚未就绪；`onLoad` 里用 `inited` 防止重复请求。
- 空态用 `inited && !list.length` 判断，避免首屏闪烁"暂无数据"。
- 分页结束条件是 `list.length >= total`，不是"本页返回为空"。

## 3. 滚动到指定元素

```javascript
// h5 环境不生效
scrollToNode(selector) {
  const query = this.createSelectorQuery();
  query
    .select(selector)
    .boundingClientRect()
    .selectViewport()
    .scrollOffset()
    .exec((res) => {
      yz.pageScrollTo({
        scrollTop: res[1].scrollTop + res[0].top,
      });
    });
},
```

注意：该方案只在微信小程序生效，H5 不生效。

## 4. 取消订单优惠

下单页取消全部优惠的三步操作：

```javascript
// 选择会员卡
this.yz.selectCustomerCard({ customerCardId: "" });
// 设置是否使用积分
this.yz.togglePointDeduction({ isUse: false });
// 选择"使用/不使用"优惠券
this.yz.selectCoupon({ chosenCouponId: -1 });
// 选择储值/礼品卡
this.yz.selectPrepayCard({ prepayCards: [] });
this.yz.watch("prepayCard", () => {
    this.yz.selectPrepayCard({ prepayCards: [] });
});
```

注意：除首次调用外，还需对 `prepayCard` 注册 `watch`，在其变化后再次清空。具体生效时机以对应下单页开放 API 文档为准。
