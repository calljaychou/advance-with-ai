## 硬性底线

只列元规则，具体条文各有唯一正文（括号内），本页不复述。

1. **先查文档**：涉及任何开放能力前，必须按需求从 <https://doc.youzanyun.com/llms.txt> 查询对应页面 / API / 插槽 / 数据文档，不得凭 Vue / Vant / 浏览器 DOM 经验推断（正文：[01](01-开发前必读与仓库结构.md)、[rules/消费端开发规则.md](../rules/消费端开发规则.md)）。
2. **生成文件不手改**：`src/api/sdk.gen.js` 只能通过 `yarn openapi` 重新生成（正文：[08](08-工程命令与检查清单.md)）。
3. **编码前通读 [06-踩坑清单.md](06-踩坑清单.md)**：模板限制（`:class`、`:key`、原生标签）、布尔属性显式绑定、可选链限制、开放组件位置、`dataReady` 约束等硬约束的唯一正文都在该分册。
4. **不做多媒体适配**：不写媒体查询、不使用响应式断点，只按设计稿目标屏幕尺寸实现（正文：[08](08-工程命令与检查清单.md)）。
5. **命令在工程目录内用 yarn 执行**，不在仓库根目录或管理后台工程执行（正文：[08](08-工程命令与检查清单.md)）。
