# 02 应用与页面配置

## 1. 应用配置 app.json

`app.json` 位于 `cloud/client/src`，用于全局配置。

| 配置项 | 作用 | 注意事项 |
| --- | --- | --- |
| `cloudPages` | 定制开放页面 | key 必须使用开放场景页面信息中的页面 key，value 为定制页面入口路径 |
| `cloudSlot` | 应用开放插槽 | 用于替换有赞应用中全局视图组件，key 必须使用应用开放插槽 key |
| `cloudCustomPages` | 新增页面 | key 为新增页面访问路径，value 为新增页面代码路径 |
| `cloudReplacePages` | 替换页面 | 用于在链接不变时完全替换开放页面，使用前先确认平台和版本支持 |
| `wxPlugins` | 微信插件配置 | 插件会打入对应应用所属分包 |

注意事项：

- `cloudPages` 的页面 key 来自开放场景的 `页面信息.md`。
- `cloudCustomPages` 的小程序 / H5 新增页面路径通常形如 `packages/${appName}/xxx/index`，其中 `${appName}` 必须使用仓库名称。
- `app.json` 中所有页面属性 key 仍需遵守 **`/index` 结尾**的项目要求，否则可能引发问题（如小程序分享场景）。
- 新增、删除、启用、禁用页面或模板后，如开发者工具不生效，需重跑 `yarn dev` 或 `yarn dev:weapp`。

### 1.1 当前配置示例

```json
{
  "cloudSlot": {},
  "cloudPages": {},
  "cloudCustomPages": {
    "packages/${PROJECT_NAME}/dealer-detail/index": "packages/dealer-detail/index",
    "packages/${PROJECT_NAME}/checkin-detail/index": "packages/checkin-detail/index",
    "packages/${PROJECT_NAME}/checkin-map/index": "packages/checkin-map/index"
  }
}
```

key 前缀 `packages/${PROJECT_NAME}/` 中的 `${PROJECT_NAME}` 即仓库名称；value 指向 `src/packages/` 下的实际目录。

## 2. 页面配置 index.json

页面配置文件位于 `src/pages/{pageName}/index.json`，通常是数组结构，支持多模板。

| 配置项 | 作用 | 注意事项 |
| --- | --- | --- |
| `name` | 模板名称 | 必填，同一页面模板名不要重复 |
| `isEnable` | 是否启用模板 | 必填，只启用需要生效的模板 |
| `cloudSlot` | 页面开放插槽配置 | 可替换、删除、追加页面插槽，必须使用文档开放的插槽 key |

示例（订单详情页定制）：

```json
[
  {
    "isEnable": true,
    "name": "订单详情页定制",
    "cloudSlot": {
      "before-order-tips": "slot-components/before-order-tips.vue"
    }
  }
]
```

插槽配置方式（一对多、删除、前后插入等）见 [04-开放插槽与开放组件.md](04-开放插槽与开放组件.md)。

## 3. 新增页面时的配置清单

新增一个自定义页面（`createPage`）通常需要同时完成：

1. 在 `src/packages/<appName>/<page-name>/` 下创建 `index.js` 与 `page.vue`（见 [03-生命周期与页面入口.md](03-生命周期与页面入口.md)）。
2. 在 `src/app.json` 的 `cloudCustomPages` 登记访问路径与代码路径。
3. H5 新增页面还需后端路由与 HTML 模板承载；跳转新增页面使用平台提供的获取路径 API，**不手写环境 URL**。
4. 页面内获取参数使用 `this.yz.getPageQuery()`。
