# 01 开发前必读与仓库结构

## 1. 开发前必读流程

接到消费端需求后按顺序执行：

1. 先确认需求类型：应用定制、页面定制、新增页面、替换页面、开放插槽、开放组件或开放 API。
2. 先读本文档系列，再按需求通过 <https://doc.youzanyun.com/llms.txt> 查询对应文档。
3. 涉及开放页面时，必须先读取对应 `页面信息.md`，确认页面 key、平台支持、开放数据、开放 API、开放插槽。
4. 涉及开放 API 时，必须读取对应 API 文档，确认参数、返回值、调用时机、是否支持中断、最低版本。
5. 涉及多端组件、Tee UI、开放组件时，必须读取组件文档，不能直接按 Vue / Vant / 浏览器 DOM 经验开发。

**不得仅凭已有经验或项目现状推断平台能力。**

## 2. 仓库结构与开发入口

`cloud` 目录是前端开放 2.0 主要开发目录，建议维持标准结构，不移动固定入口文件。

| 路径 | 职责 |
| --- | --- |
| `cloud/client` | 消费者端定制，使用 Tee 多端框架，支持 H5 与微信小程序 |
| `src/app.js` | 应用级定制入口，使用 `extendApp` |
| `src/app.json` | 应用级配置入口，配置 `cloudPages`、`cloudSlot`、`cloudCustomPages`、微信插件等 |
| `src/pages/{pageName}/index.js` | 页面级逻辑入口，使用 `extendPage` |
| `src/pages/{pageName}/index.json` | 页面级配置，配置模板启用状态和页面开放插槽 |
| `src/pages/{pageName}/slot-components/` | 页面级开放插槽组件目录 |
| `src/slot-components/` | 应用级开放插槽组件目录 |
| `src/packages/${appName}/...` | 新增页面或独立分包目录 |
| `src/api/` | 请求封装与生成 SDK：`sdk.gen.js`（生成，勿改）、`index.js`、`request.js`、`type.d.ts` |
| `src/components/` | 可复用的 Vue / Tee 组件（如 `custom-form`、`custom-rich-text`、`checkin-map`） |
| `src/styles/` | 全局样式，`global.scss` 内置 `rpx()` 单位函数 |
| `src/utils/` | 公共工具、`componentHook.js`、`store/` 状态辅助 |

## 3. 现有代码分布

| 类型 | 位置 | 说明 |
| --- | --- | --- |
| 定制开放页面（插槽） | `src/pages/order-detail/` | 目前接入的是订单详情页定制，含 `index.js`、`index.json`、`slot-components/before-order-tips.vue` |
| 新增页面（分包） | `src/packages/<appName>/` | `dealer-detail`、`checkin-detail`、`checkin-map`、`activity-list`、`activity-detail`、`activity-registration-detail` |
| 应用级插槽组件 | `src/slot-components/` | 目前为空，新增应用级插槽组件时放这里 |

新增页面通常要同时改 `src/app.json` 的 `cloudCustomPages`，见 [02-应用与页面配置.md](02-应用与页面配置.md)。

## 4. 构建与测试

- 小程序构建报错"没有相关小程序定制代码，无法打包 ... `mp-extension/extension.json`"时，可按发布文档创建 `mp-extension/extension.json`。
- 内容修改完成后仅使用工程已有的 ESLint 与 Prettier 检查（配置为 `.eslintrc`、`.prettierrc`）；不为检查新增依赖。
- 不需要额外执行 `yarn build` 等构建命令，除非用户明确要求或任务本身必须构建验证。
