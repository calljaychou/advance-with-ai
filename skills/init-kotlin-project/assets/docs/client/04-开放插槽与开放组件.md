# 04 开放插槽与开放组件

## 1. 开放插槽

开放插槽是有赞提前开放的可替换位置，**未开放的插槽无法使用**。具体 key 与能力以 <https://doc.youzanyun.com/llms.txt> 查到的插槽文档为准。

### 1.1 插槽类型

| 类型 | 配置位置 | 生效范围 |
| --- | --- | --- |
| 页面开放插槽 | 页面 `index.json` 的 `cloudSlot` | 只对当前页面生效 |
| 应用开放插槽 | `app.json` 的 `cloudSlot` | 对应用级全局组件生效 |

### 1.2 插槽配置方式

| 方式 | 写法 | 说明 |
| --- | --- | --- |
| 替换默认组件 | `"slot-key": "slot-components/slot-key.vue"` | 最常见 |
| 一对多替换 | `"slot-key": ["slot-components/a.vue", "slot-components/b.vue"]` | 按数组顺序渲染 |
| 删除默认组件 | `"slot-key": null` | 前提是该插槽允许删除 |
| 前后插入 | `before-${slotName}`、`after-${slotName}` | 每个 slot 默认支持 |
| 配置化定制 | 直接传配置对象 | 部分插槽支持，避免重写复杂组件 |
| Props 注入 | — | 循环或上下文场景下，插槽会通过 props 注入上下文数据，字段以对应插槽文档为准 |

### 1.3 动态显隐

| 能力 | 用法 | 说明 |
| --- | --- | --- |
| 隐藏前置判断 | `this.yz.before[SlotName]Show(callback)` | 需在 `created` 中注册，`slotName` 使用**大驼峰** |
| 动态显示 / 隐藏 | `this.yz.toggle[SlotName]Show({ isShow: boolean })` | — |

只有通过 `toggle[SlotName]Show` 隐藏的插槽，才能再通过该 API 显示。

### 1.4 插槽组件约束

- 开放组件必须放在**页面层或插槽层**，不能放在自定义组件中。
- 插槽组件必须设置稳定的 `name`，因为 `this.yz.refs` 的 key 与组件 `name` 相关。
- 页面级插槽组件放 `src/pages/{pageName}/slot-components/`；应用级插槽组件放 `src/slot-components/`。

## 2. 开放组件

开放组件可以复用开放页面中的默认组件，**无需引入，可直接使用**。

### 2.1 用法

```html
<cloud-component cloud-id="id" cloud-class="class" />
```

- 所有开放组件都有 `cloudId` 和 `cloudClass`，用于查询组件实例。
- `this.yz.queryComponentById(id)` 查询单实例。
- `this.yz.queryComponentByClass(className)` 查询多实例。
- 依赖开放组件数据或方法时，建议放在组件实例 `dataReady` 回调中执行。

### 2.2 数据与能力边界

| 维度 | 规则 |
| --- | --- |
| 数据 | 只读，不支持直接写；数据写入必须通过开放 Method |
| Method | 通常返回 Promise，适合主动调用业务能力 |
| Hook | 用于拦截默认业务流程，部分 hook 可通过 `Promise.reject()` 中断，也可返回处理后的数据影响后续流程 |
| Event | 用于监听变更，不支持返回值，不支持中断 |
| Slot | 部分开放组件提供 slot，用于定制局部模块 |

### 2.3 约束

- 开放组件内部**不建议**使用 Tee UI 组件，大概率导致开放组件失效。
- 所有开放组件都有 `cloudId` / `cloudClass`，不要自行构造实例。

## 3. 示例：订单详情页插槽定制

`src/pages/order-detail/index.json`：

```json
[
  {
    "isEnable": true,
    "name": "订单详情页定制",
    "cloudSlot": {
      "before-order-tips": "slot-components/before-order-tips.vue"
    }
  }
]
```

对应组件位于 `src/pages/order-detail/slot-components/before-order-tips.vue`。
