# 03 生命周期与页面入口

三个入口都**只能调用一次、不需要引入或注册**，区别在于调用位置与适用场景。

| 入口 | 调用位置 | 用途 |
| --- | --- | --- |
| `extendApp` | 根目录 `app.js` | 扩展全局 App 实例 |
| `extendPage` | 页面目录 `index.js` | 扩展开放页面 Page 实例 |
| `createPage` | 新增 / 替换页面目录的 `index.js` | 新增页面或替换页面 |

## 1. extendApp

- 用于扩展全局 App 实例，必须在根目录 `app.js` 中调用。
- 支持 `onLaunch`、`onShow`、`onHide`、`methods`。
- `onShow`、`onHide` 只支持小程序，H5 不支持。
- 通过 `this.yz.app` 可在页面或组件中访问 App 实例。**注意这不是微信 `getApp` 实例。**

## 2. extendPage

- 用于扩展开放页面 Page 实例，必须在页面目录 `index.js` 中调用。
- 支持 `created`、`beforeMount`、`mounted`、`destroyed`、`dataReady`、`methods`。

各钩子的适用场景：

| 钩子 | 适合做的事 |
| --- | --- |
| `created` | 注册 hook / event，**不发请求** |
| `beforeMount` | 预留，页面初始化请求不放这里 |
| `mounted` | 需要 DOM / 实例已就绪的操作，**不发初始化请求** |
| `dataReady` | **页面初始化请求统一放这里**；读取 `this.yz.data`、`this.yz.getPageQuery()`、调用 `this.yz.app.getApi()` |
| `destroyed` | 清理事件和定时器 |

- `onPullDownRefresh`、`onReachBottom`、`onPageScroll` 等小程序页面事件需注册在 `extendPage` 中，写在 `page.vue` 中**不生效**。
- `onShow`、`onHide` 只支持小程序，H5 不支持。
- 通过 `this.yz.page` 可在当前页面内访问 Page 实例；应用级定制组件**无法**访问页面实例。

### 页面初始化请求必须放 `dataReady`

`dataReady` 是 `this.yz` 就绪的回调时机。在 `created` / `mounted` 里发初始化请求，会与平台注入 `this.yz` 的过程赛跑，出现 `this.yz.app` 为空、`this.yz.data.user` 取不到 `yzOpenId`、`getPageQuery()` 拿不到参数等随机失败。因此页面内**所有**首屏请求（详情、列表首屏、依赖用户身份的查询）都必须在 `dataReady` 中发起。

```javascript
export default {
  // 只做事件注册，不发请求
  created() {
    yz.event.on(SCROLL_EVENT, this.onPageScroll);
  },
  // 首屏请求统一在此发起，此时 this.yz 数据与方法已就绪
  dataReady() {
    const info = ((this.yz.data && this.yz.data.user) || {}).info || {};
    if (!info.yzOpenId) {
      this.loading = false;
      this.errorMessage = "未获取到用户信息，请稍后重试";
      return;
    }
    this.loadDetail(info.yzOpenId);
  },
  destroyed() {
    yz.event.off(SCROLL_EVENT, this.onPageScroll);
  },
  methods: {
    async loadDetail(yzOpenId) {
      const query = this.yz.getPageQuery() || {};
      const res = await this.yz.app.getApi().getClientActivityDetail({
        yzOpenId: yzOpenId,
        activityId: Number(query.activityId),
      });
      this.activity = res.data;
    },
  },
};
```

要点：

- 反例：把 `this.loadDetail()` 写在 `created` / `beforeMount` / `mounted` 里，即使本地偶发能跑通，H5 冷启动或小程序切后台回前台时仍会失败。
- 参数读取（`this.yz.getPageQuery()`）与依赖用户数据的接口调用一起放 `dataReady`，不要提前缓存到 `created`。
- 需要监听 `this.yz.data` 后续变化时，在 `dataReady` 里用 `this.yz.watch` 注册，而不是 `computed`（见 [05-通信与安全.md](05-通信与安全.md)）。
- 用户交互触发的请求（分页加载、提交、取消等）仍放在 `methods` 中由事件调用，不受此约束。
- 该约束针对**页面**。自定义组件的 `dataReady` 在小程序不生效（见 [06-踩坑清单.md](06-踩坑清单.md)），组件内不承担首屏请求，由页面在 `dataReady` 中取数后通过 `props` 下发。

## 3. createPage

- 用于新增页面或替换页面，必须在新增 / 替换页面目录的 `index.js` 中调用。
- 必须提供 `render`，且 `render` 需要返回 Tee 组件。
- `config` 当前主要用于微信小程序页面配置。
- `onShareAppMessage`、`onShareTimeline`、`onPullDownRefresh`、`onReachBottom`、`onPageScroll` **只在小程序有效**，需注册在 `createPage` 中，写在 `page.vue` 中不生效。
- 新增页面通常需要 `index.js` 与 `page.vue`。
- H5 新增页面还需要后端路由和 HTML 模板承载，跳转新增页面应使用平台提供的获取路径 API，不手写环境 URL。
- 新增页面内获取参数使用 `this.yz.getPageQuery()`。

## 4. 平台差异速查

| 能力 | H5 | 微信小程序 |
| --- | --- | --- |
| `onShow` / `onHide` | 不支持 | 支持 |
| `onPullDownRefresh` / `onReachBottom` / `onPageScroll` | 不支持 | 支持，且必须注册在 `extendPage` / `createPage` |
| `onShareAppMessage` / `onShareTimeline` | 不支持 | 支持，注册在 `createPage` |
| 新增页面承载 | 需后端路由 + HTML 模板 | 分包即可 |
