# 管理后台开发规则

适用 `${PROJECT_NAME}-ui/vite-react-page`（React + Vite + TypeScript + React Router + Ant Design + Tailwind CSS + styled-components）。

**必读**：[docs/admin/README.md](../admin/README.md) —— 目录职责、独立页面机制、组件/Hook 复用、样式组织、命名规范均以该系列分册为准。本文件只列硬性判定条件。

## 1. 前置动作

1. 先读 `docs/admin/README.md`，按任务进入对应分册（`02-独立页面与路由.md` 讲路由、`03-页面与组件设计.md` 讲拆件、`05-样式规范.md` 讲样式）。
2. 开发新能力前依次检查 `src/components/`、`src/hooks/`、`src/utils/`、`src/types/`、`src/api/`；能复用或小范围扩展时**不得重复实现**。
3. UI 基础能力优先用 Ant Design，不重复封装功能相同的基础组件。

## 2. 目录职责

| 路径 | 职责 |
| --- | --- |
| `src/main.tsx` | 默认管理后台应用挂载入口 |
| `src/pages/` | 页面及独立页面构建入口 |
| `src/components/` | 跨页面复用组件；新增页面前必须优先检查 |
| `src/hooks/` | 请求、列表、弹窗、事件等公共 Hook；禁止在页面中重复实现已有能力 |
| `src/router/` | 默认应用路由、路由工具与公共路由组件 |
| `src/api/generated/` | OpenAPI 生成产物，**不得手动修改** |
| `src/api/config.ts` | 统一请求实例、拦截器与生成 SDK 的运行时配置 |

## 3. 页面拆分

- 页面按需拆分为 `App.tsx`、`components/`、`hooks/`、`utils.ts`、`constants.ts`、`types.ts`、`styles.ts`；**不得**把业务组件、工具、类型、样式全堆在 `App.tsx`。
- 一个组件文件只定义一个 React 组件；可独立命名、接收独立 Props 或维护独立状态的子组件必须拆为独立文件。

## 4. 样式

- 优先 Tailwind CSS 实现布局与常规样式；复杂选择器、动态主题、第三方组件覆盖再用 styled-components。
- 不同页面、不同组件的 styled-components 必须放各自独立样式文件，不得集中到单个页面级或全局样式文件。
- 覆盖 Ant Design 样式时限制选择器作用域；读取主题色优先用 Ant Design Token，不硬编码。

## 5. 独立页面与路由（MultiPageAutoPlugin）

`vite.config.ts` 使用 `MultiPageAutoPlugin`（`vite-plugin-multipage-auto`）自动发现多页面入口：

- `src/pages/` 下页面目录若存在 `main.tsx`，即被识别并打包为独立页面。
- 新增独立页面必须在 `src/pages/<页面目录>/main.tsx` 配置 React 挂载入口，按现有页面结构引入该页面的 Router、全局样式与必要 Provider。
- 关联的详情页、编辑页通过该页面的 `router` 统一组织，优先路由懒加载，**不要**为它们分别添加 `main.tsx`。
- 一个独立页面目录只保留一个 `main.tsx` 构建入口。
- 本地调试独立页面必须在 `src/router/routes.tsx` 登记路由（`path` 用页面目录名，`element` 指向该页面 `App.tsx`）；否则 `npm run dev` 无法进入。
- 参考 `src/pages/list/main.tsx` 与 `src/pages/list/router/index.tsx`。完整机制见 [docs/admin/02-独立页面与路由.md](../admin/02-独立页面与路由.md)。

```plaintext
src/pages/<页面目录>/
├── main.tsx                 # MultiPageAutoPlugin 识别的独立构建入口
├── App.tsx                  # 入口页面组件
├── router/
│   └── index.tsx            # 该单页应用的路由配置
└── <关联页面>/              # 详情、编辑等路由页面，不单独添加 main.tsx
```

## 6. API 与命令（均在 `${PROJECT_NAME}-ui/vite-react-page` 下执行）

- 后端提供 Swagger/OpenAPI 后执行 `npm run openapi` 生成 `src/api/generated/`；页面必须复用 `src/api/config.ts` 的统一请求配置，不得绕开拦截器重复创建请求实例。

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动管理后台开发环境 |
| `npm run dev:scan` | 带 React Scan 的开发环境（`vite --mode scan`） |
| `npm run openapi` | 生成管理后台 API SDK |
| `npm run build` | 构建管理后台工程，仅在任务需要构建验证时执行 |

## 7. 禁止事项

- 不做多媒体适配：不写 `@media`，不使用 `sm:`、`md:`、`lg:`、`xl:`、`2xl:` 等响应式断点前缀。
- 不手动修改 `src/api/generated/`。
- 不绕开 `src/api/config.ts` 自建请求实例。
- 不把页面私有样式写入全局样式文件，不无作用域覆盖 Ant Design。
