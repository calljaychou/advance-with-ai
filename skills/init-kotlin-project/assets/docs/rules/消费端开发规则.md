# 消费端开发规则

适用 `${PROJECT_NAME}-ui/cloud/client`（Vue + Tee 多端框架，H5 与微信小程序）。

**本文件只列强制判定条件，每条一句话；不写实现细节、不抄命令表、不重复踩坑现象。**

- 配置格式、页面 key、平台差异以 [docs/client/README.md](../client/README.md) 及其分册为准。
- 具体写法与报错现象见 [06-踩坑清单.md](../client/06-踩坑清单.md)，命令见 [08-工程命令与检查清单.md](../client/08-工程命令与检查清单.md)。

## 1. 前置动作

修改任何页面、应用配置或开放能力前：

1. 先读 `docs/client/README.md` 定位分册：配置 → `02`，入口与生命周期 → `03`，插槽 / 组件 → `04`，`06-踩坑清单` 必读。
2. 按需求从 <https://doc.youzanyun.com/llms.txt> 检索对应的有赞云能力文档，确认配置格式、端能力差异与使用限制。
3. 涉及开放页面时，确认页面 key 来自该场景的 `页面信息.md`。

**不得**仅凭 Vue / Vant / 浏览器 DOM 经验推断开放能力行为。

## 2. 目录与生成文件

- 不得移动固定入口：`src/app.js`（`extendApp`）、`src/app.json`、`src/pages/{pageName}/index.js`（`extendPage` / `createPage`）。
- `src/api/sdk.gen.js` 为 OpenAPI 生成产物，**只能**通过 `yarn openapi` 重新生成，不得手改。
- 目录职责全表见 [01-开发前必读与仓库结构.md](../client/01-开发前必读与仓库结构.md)。

## 3. 编码判定条件

- 沿用现有 JS / Vue / SCSS 风格；优先复用 Tee UI、现有组件与工具。
- 同时考虑 H5 与微信小程序：不得只按浏览器 DOM 或单一平台行为实现。
- 消费端 API 非特殊情况不得手写；确需手改 `src/api/index.js` 等文件的，先说明原因并确认方案。
- **页面初始化请求必须写在 `dataReady`**：`created` 只注册 hook / event，`mounted` 只做 DOM / 实例操作。原因、示例与反例见 [03-生命周期与页面入口.md](../client/03-生命周期与页面入口.md)。
- **模板不得直接使用原生 `input` / `span`**：输入框用 Tee UI `Field`（注册为 `t-field`），文本用 `text`，布局用 `view`。完整写法与样式覆盖见 [06-踩坑清单.md](../client/06-踩坑清单.md)。
- **布尔属性必须显式绑定**：一律 `:attr="true"` / `:attr="false"`，禁止简写 `attr`。
- 不做多媒体适配：不写媒体查询、不用响应式断点。

## 4. 禁止事项

- 不使用文档禁止的非多端 API（浏览器 `window` / `localStorage` 等、小程序 `wx` / `getApp` 等），改用开放 API。
- 不为通过检查而新增依赖；只使用工程已有的 ESLint / Prettier。
